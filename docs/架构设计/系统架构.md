# 系统架构

## 架构概览

MeetFlow 是一个纯前端 Next.js 应用（含 API Routes），采用组件化架构。

```
web/src/
├── app/               # Next.js App Router
│   ├── page.tsx       # 主页面 (MeetFlowApp 组件)
│   ├── layout.tsx     # 根布局
│   └── api/           # API Routes
│       ├── ai/        # LLM 对话接口
│       └── asr/       # 语音识别接口
├── components/        # UI 组件
│   ├── layout/        # 布局组件 (Header, Sidebar)
│   ├── canvas/        # 画布编辑器 (4 种模式)
│   ├── voice/         # 语音面板
│   ├── ai/            # AI 功能
│   └── ui/            # shadcn/ui 基础组件
├── hooks/             # 自定义 Hook
└── lib/               # 工具函数
```

## 核心组件

### 页面布局

MeetFlowApp 是顶层组件，管理全局状态：

- `canvasMode`: 当前画布模式 (outline / mindmap / whiteboard / template)
- `aiChatOpen`: AI 侧边栏开关
- `voicePanelWidth`: 语音面板宽度

布局结构：`Header → [Sidebar | CanvasArea | VoicePanel | AIChatSidebar]`

### 画布模块 (`components/canvas/`)

| 组件 | 功能 |
|------|------|
| CanvasArea | 画布容器，按 mode 切换子组件 |
| OutlineEditor | 大纲编辑器（富文本） |
| MindMapEditor | 思维导图（simple-mind-map） |
| WhiteboardEditor | 白板绘图（Excalidraw） |
| TemplateEditor | 模板系统（SWOT 等预设模板） |

### 语音模块 (`components/voice/`)

| 组件 | 功能 |
|------|------|
| VoicePanel | 语音录制面板，含波形显示和 ASR 转写 |
| SummaryDialog | 录音总结弹窗 |

### AI 模块 (`components/ai/`)

| 组件 | 功能 |
|------|------|
| AIChatSidebar | 侧边栏对话（支持 streaming） |
| AIPanel | 底部快捷操作面板 |

### 布局模块 (`components/layout/`)

| 组件 | 功能 |
|------|------|
| Header | 顶部导航栏 |
| Sidebar | 左侧模式切换栏 |

## 数据流

### AI 对话（AIChatSidebar / AIPanel）

```
用户输入
  ↓
POST /api/ai  { messages, stream: true }
  ↓
云雾中转 (yunwu.ai) → GPT-5.4
  ↓
SSE 流式响应 (data: {...delta...})
  ↓
ReadableStream 逐 chunk 解析 → 实时更新消息内容
```

- 中断支持：AbortController，切换对话时取消上一次请求
- 非流式模式：`stream: false`，用于 AIPanel 总结生成（`data.choices[0].message.content`）

### 语音识别（VoicePanel）

```
麦克风授权 (getUserMedia)
  ↓
AudioContext + ScriptProcessorNode (4096 samples, 单声道)
  ↓
Float32 → PCM16 16kHz 重采样 → base64 编码
  ↓
GET /api/asr  → 返回 { wsUrl, apiKey, model }
  ↓
WebSocket 连接 DashScope Qwen3-ASR-Flash-Realtime
  ↓
session.update (model, pcm16, server_vad)
  ↓
input_audio_buffer.append { audio: base64 } (每帧)
  ↓
onmessage: transcript delta → 追加转录列表
```

- 录音开始时清空 Mock 转录，切换为实时模式
- 错误/关闭时自动清理 AudioContext、MediaStream、WebSocket

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `1` | 切换到大纲模式 |
| `2` | 切换到思维导图 |
| `3` | 切换到白板 |
| `4` | 切换到模板 |
| `⌘/` | 打开/关闭 AI 助手 |

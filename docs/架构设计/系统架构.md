# 系统架构

## 架构概览

MeetFlow 是一个纯前端 Next.js 应用（含 API Routes），采用组件化架构。

```
web/src/
├── app/               # Next.js App Router
│   ├── page.tsx       # 主页面 (MeetFlowApp 组件)
│   ├── layout.tsx     # 根布局
│   └── api/           # API Routes
│       ├── ai/        # LLM 对话接口（Vercel AI SDK，3 工具，流式+非流式）
│       ├── asr/       # ASR 配置接口（返回本地代理地址 ws://localhost:4928）
│       ├── search/    # SearXNG 真实搜索接口（localhost:8888）
│       ├── copilotkit/ # CopilotKit runtime 端点（暂禁用，stub 保留）
│       └── projects/  # 项目 CRUD 接口
├── components/        # UI 组件
│   ├── layout/        # 布局组件 (Header, Sidebar, ProjectPanel)
│   ├── canvas/        # 画布编辑器 (4 种模式)
│   ├── voice/         # 语音面板
│   ├── ai/            # AI 功能
│   └── ui/            # shadcn/ui 基础组件
├── hooks/             # 自定义 Hook
│   ├── useProject.ts  # 项目 Context + Provider
│   └── useWorkspace.ts # 全局 Workspace Context (画布+转录数据总线，供 AI 读取)
└── lib/               # 工具函数
    └── logger.ts      # pino 结构化日志（v2.1 新增）
```

`components/ai/` 下的 AI 相关文件：

```
components/ai/
├── AIChatSidebar.tsx      # 统一 AI 侧边栏（v2.1 合并重写）
├── ToolCallDisplay.tsx    # 工具调用可视化（v2.1 新增）
├── CopilotKitProvider.tsx # 暂禁用
└── CopilotKitWorkspace.tsx # 暂禁用
```

> `AIPanel.tsx` 已于 v2.3 删除（死代码，组件体只有 `return null`）。

运行时生成目录（已 gitignore）：

```
web/logs/
├── app.log       # pino 主日志（dev: pretty，prod: JSON）
└── audit.jsonl   # 结构化审计日志（每行一个 JSON 对象）
```

数据持久化目录（运行时生成，已 gitignore）：

```
web/data/
└── projects/
    ├── index.json          # 项目列表索引（id、name、createdAt、updatedAt）
    └── <uuid>/             # 每个项目独立目录
        ├── meta.json       # 项目元数据 + canvasMode
        ├── outline.html    # 大纲内容
        ├── mindmap.json    # 思维导图数据
        ├── whiteboard.json # 白板数据
        ├── templates.json  # 模板数据
        ├── transcripts.json# 语音转录列表
        └── chat.json       # AI 对话历史
```

## 核心组件

### 页面布局

MeetFlowApp 是顶层组件，管理全局状态：

- `canvasMode`: 当前画布模式 (outline / mindmap / whiteboard / template)
- `aiChatOpen`: AI 侧边栏开关
- `voicePanelWidth`: 语音面板宽度

布局结构：`Header → [Sidebar | CanvasArea | VoicePanel | AIChatSidebar]`

### 画布模块 (`components/canvas/`)

| 组件 | 功能 |
|------|------|
| CanvasArea | 画布容器，按 mode 切换子组件 |
| OutlineEditor | 大纲编辑器（富文本，持久化到 `outline.html`）；**卸载即存**：模式切换时绕过 debounce 立即 flush 保存；**AI 自命名**：首次输入 3s 后调用 `/api/ai` 生成项目名称 |
| MindMapEditor | 思维导图（simple-mind-map，持久化到 `mindmap.json`） |
| WhiteboardEditor | 白板绘图（Excalidraw，持久化到 `whiteboard.json`） |
| TemplateEditor | 模板系统（SWOT 等预设模板，持久化到 `templates.json`） |

### 语音模块 (`components/voice/`)

| 组件 | 功能 |
|------|------|
| VoicePanel | 语音录制面板，含波形显示、ASR 转写、一键 AI 总结；转录同步到 WorkspaceContext；ASR 断线自动重连（最多 3 次，5s 间隔）；流式逐字实时显示（监听 `response.audio_transcript.delta`），说话人区分（VAD 话轮切换时递增颜色），当前话轮呼吸灯动画；**v2.3**：`mediaDevices` 可用性 guard，错误消息在非录音状态下也显示 |
| SummaryDialog | 录音总结弹窗，动态展示 AI 生成的 markdown 内容，支持 loading 状态 |

### AI 模块 (`components/ai/`)

| 组件 | 功能 |
|------|------|
| AIChatSidebar | **统一 AI 侧边栏**（v2.1 合并 AIPanel）：4 个 Tab — 对话（streaming SSE + workspace 上下文注入）/ 总结 / 搜索 / 自动填充；底部悬浮按钮触发 |
| ToolCallDisplay | AI 工具调用可视化组件（v2.1 新增）；展示字段：工具名称、状态（pending/running/completed/error）、耗时、输入/输出摘要；嵌入 AIChatSidebar 对话 Tab |

### 布局模块 (`components/layout/`)

| 组件 | 功能 |
|------|------|
| Header | 顶部导航栏；**v2.3**：标题读取 `currentProject.meta.name`，点击内联编辑，确认后调用 `renameProject` 持久化；分享/下载/设置按钮改为 `toast.info()` 提示 |
| Sidebar | 左侧模式切换栏；导出按钮：将大纲 HTML 转 Markdown 下载为 `<项目名>_<日期>.md` |
| ProjectPanel | 左侧项目列表面板（创建/切换/删除，可折叠；显示最近编辑时间） |

### 日志系统 (`lib/logger.ts`)

v2.1 新增，使用 pino 结构化日志替代 console.log/error：

| 导出 | 说明 |
|------|------|
| `logger` | 全局 pino 实例，dev 环境自动启用 pino-pretty 美化 |
| `apiLogger(routeName)` | 工厂函数，生成带 route 标签的子 logger；记录 method/path/status/duration_ms |

所有 API Routes（`/api/ai`、`/api/search`、`/api/asr`、`/api/projects`、`/api/projects/[id]`）均引入 apiLogger，请求入口和出口各打一条日志。

### CopilotKit 集成

v2.1 新增，当前**暂时禁用**：`CopilotKitProvider` 已从 `page.tsx` 注释掉（缺少 `@copilotkit/runtime` 服务端包）。组件和 API 端点文件保留，待安装服务端包后重新启用。

**恢复步骤**：`npm install @copilotkit/runtime`，然后在 `page.tsx` 重新挂载 `<CopilotKitProvider>`。

### Workspace Context (`hooks/useWorkspace.ts`)

全局数据总线，供 AI 模块读取实时画布和转录内容。

| 字段 / 方法 | 说明 |
|-------------|------|
| `outlineHTML` | 大纲编辑器当前 HTML |
| `mindmapText` | 思维导图节点文本（逗号分隔） |
| `whiteboardText` | 白板文本元素（空格分隔） |
| `templateText` | 当前模板所有单元格文本 |
| `transcripts` | 语音转录条目列表 |
| `setOutlineHTML` / `setMindmapText` / ... | 各编辑器写入接口 |
| `getContextSummary()` | 序列化为 AI system prompt 摘要（限 4000 字符） |

`WorkspaceProvider` 挂载于 `page.tsx` 的 `ProjectProvider` 内层，所有画布编辑器均通过 `useWorkspace()` 写入数据。

### 项目管理模块

项目管理通过三层协作实现：

**数据存储**：JSON 文件，路径为 `web/data/projects/<uuid>/`，每个项目独立存储画布、转录、AI 对话数据，完全隔离。

**API Routes**（`app/api/projects/`）：

| 路由 | 方法 | 功能 |
|------|------|------|
| `/api/projects` | GET | 获取项目列表 |
| `/api/projects` | POST | 创建新项目，初始化所有数据文件 |
| `/api/projects/[id]` | GET | 加载完整项目数据 |
| `/api/projects/[id]` | PUT | 更新项目字段（支持部分更新，自动更新 updatedAt） |
| `/api/projects/[id]` | DELETE | 删除项目目录及索引条目 |

**前端**（`hooks/useProject.ts`）：

- `ProjectProvider`：全局 Context，挂载于 `page.tsx` 根层，应用启动时自动加载项目列表
- `useProject()`：提供 `projects`、`currentProject`、`createProject`、`switchProject`、`deleteProject`、`renameProject`、`saveField`
- `saveField`：500ms 防抖自动保存；**v2.3 竞态修复**：调用时快照 `currentProjectId`（而非在 setTimeout 里从 ref 读），确保 debounce 到期时写入正确项目
- `renameProject`：直接调用 `PUT /api/projects/[id]`，同时更新本地 `currentProject.meta.name` 状态

**页面集成**（`app/page.tsx`）：

- 无项目时显示欢迎页（`FolderOpen` 图标 + 创建按钮）
- 有项目时渲染完整编辑器布局（Sidebar + CanvasArea + VoicePanel + AIChatSidebar）
- AI 侧边栏悬浮按钮仅在有活跃项目时显示

## 数据流

### AI 对话（AIChatSidebar — 统一侧边栏）

```
用户输入
  ↓
workspace.getContextSummary()  → 序列化当前画布+转录（限 4000 字符）
  ↓
POST /api/ai  { messages, context, stream: true/false }
  ↓
Vercel AI SDK (streamText / generateText)
  → @ai-sdk/openai + 云雾中转 (yunwu.ai) → GPT-5.4
  ↓
流式模式: SSE (data: {choices:[{delta:{content}}]}) → ReadableStream 解析 → 实时更新
  工具调用步骤: text-delta / tool-call / tool-result → 内联进度文本推送前端
非流式模式: JSON { choices:[{message:{content}}] } → 直接渲染
```

- `context` 字段携带 workspace 序列化数据，由 API 注入到 system prompt
- 中断支持：AbortController（AIChatSidebar）
- 非流式模式：`stream: false`，用于 VoicePanel 一键总结、AIChatSidebar 总结 Tab
- **AI 工具（v2.2+）**：`stopWhen: stepCountIs(5)` 防止无限循环

| 工具名 | 触发条件 | 实现 |
|--------|----------|------|
| `searchWeb` | 用户要求搜索/查找信息 | 调用 `GET http://localhost:8888/search`（SearXNG） |
| `fetchWebPage` | 搜索后需要查看页面详情 | `fetch(url)` + HTML strip → 截断至 3000 字符 |
| `getCurrentTime` | 用户问当前时间/日期 | `new Date().toLocaleString("zh-CN", { timeZone: "Asia/Shanghai" })` |

### 信息检索（/api/search）

```
用户输入搜索词
  ↓
POST /api/search  { query, count }
  ↓
SearXNG 实例 (localhost:8888) → 真实搜索结果
  ↓
{ results: [{ title, url, content, score }] }
```

- 依赖本地 SearXNG 实例运行在 port 8888
- SearXNG 不可用时返回 `{ results: [], error: "搜索服务暂不可用" }`

### 语音识别（VoicePanel）

```
navigator.mediaDevices?.getUserMedia 可用性检查
  ↓（不可用时立即显示错误，终止流程）
麦克风授权 (getUserMedia)
  ↓
AudioContext + ScriptProcessorNode (4096 samples, 单声道)
  ↓
Float32 → PCM16 16kHz 重采样 → base64 编码
  ↓
GET /api/asr  → 返回 { wsUrl: "ws://localhost:4928", model }
  ↓
WebSocket 连接本地 ASR 代理 (port 4928)，代理转发至 DashScope Qwen3-ASR-Flash-Realtime
  ↓
session.update (model, pcm16, server_vad)
  ↓
input_audio_buffer.append { audio: base64 } (每帧)
  ↓
onmessage: transcript delta → 追加转录列表
```

- 初始转录列表为空，录音开始后切换为实时模式
- 转录条目实时同步到 WorkspaceContext，供 AI 模块读取
- ASR WebSocket 断开时自动重连：最多重连 3 次（`MAX_RECONNECT = 3`），每次 5s 延迟；超限后显示手动重试提示
- 录音停止时调用 `saveField("transcripts", [...])` 持久化到项目数据
- 错误/关闭时自动清理 AudioContext、MediaStream、WebSocket
- **v2.3**：`mediaDevices` 不可用时（无权限或非 HTTPS 环境）显示错误提示，不卡死在初始状态

### 大纲持久化（OutlineEditor）

```
用户输入内容
  ↓
onInput → setOutlineHTML(WorkspaceContext) + 标记 dirty
  ↓
saveField("outline", html)  — 500ms debounce
  ↓（模式切换时）
组件卸载 useEffect cleanup → 若 dirty，立即 fetch PUT /api/projects/[id]（bypass debounce）
```

- **卸载即存**保证模式切换不丢数据（不等 debounce 计时器）
- **AI 自命名**：首次输入满 3s 且未命名时，调用 `POST /api/ai`（非流式）生成 ≤5 字项目名，调用 `renameProject`

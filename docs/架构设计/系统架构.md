# 系统架构

## 一句话定位

**录音 → 实时 ASR 字幕 → VAD 切句 → 声纹归属 → 跨会议识别 → AI 总结**。声纹库越用越准，所有配置通过 UI 管理。

---

## 总体拓扑

```

  ├─ /                录音页：通道选择 + 实时字幕 + 声纹确认
  ├─ /voiceprints     声纹库：角色列表 + 样本播放 + 改名 + 合并
```

## 数据模型（SQLite `data/vp.db`）

```sql
-- 声纹角色（跨会议持久）
speakers (
  id TEXT PK,
  name TEXT,               -- "张三" / "新用户 3"
  sample_count INTEGER,
  centroid BLOB,           -- 192×float32，L2 归一化平均向量
  created_at INTEGER,
  updated_at INTEGER
)

-- 会议记录
meetings (
  id TEXT PK,
  title TEXT,              -- "会议 2026-05-20 13:30"
  started_at INTEGER,
  ended_at INTEGER         -- NULL = 录音进行中
)

-- 发言段
utterances (
  id TEXT PK,
  meeting_id TEXT,
  speaker_id TEXT,         -- FK → speakers.id，可被用户修正
  text TEXT,               -- ASR 识别文字
  start_ms INTEGER,
  end_ms INTEGER,
  audio_path TEXT,         -- data/segments/<uuid>.wav
  raw_embedding BLOB,      -- 192×float32，原始（用于重算 centroid）
  confidence REAL,         -- 余弦相似度
  needs_review INTEGER,    -- 0=自动归 / 1=待确认
  created_at INTEGER
)

-- 全局配置（R10 新增）
settings (
  key TEXT PK,
  value TEXT               -- 明文存储，前端展示时脱敏
)
-- R10 核心 key: anthropic_api_key, anthropic_base_url, anthropic_model,
--               agent_system_prompt, dashscope_api_key
-- R11 新 key:   agent_api_key(fallback→anthropic_api_key), agent_base_url,
--               asr_api_key(fallback→dashscope_api_key), asr_ws_url, voiceprint_url

-- AI 问答对话历史（R11 新增）
meeting_chats (
  id TEXT PK,
  meeting_id TEXT,         -- FK → meetings.id
  role TEXT,               -- 'user' | 'assistant'
  content TEXT,            -- Markdown 格式内容
  created_at INTEGER
)
```

> `meeting_summaries` 表在 R9 plan 中设计但**未实际建表**；AI 总结目前以 Markdown 文件持久化到 `data/agent-memory/<meetingId>-summary.md`。

## 核心数据流

### A. 录音通道 mux → ASR → 声纹归属

```
浏览器录音页 (page.tsx)
  │
  ├─1─ 通道 mux（R8，startRecording()）:
  │
  │      麦克风
  │        getUserMedia({ audio: deviceId || true })
  │        captureStream = micStream
  │
  │      系统音频
  │        getDisplayMedia({ video: true, audio: {echoCancellation:false} })
  │        ds.getVideoTracks().forEach(t => t.stop())   ← 立即丢弃视频
  │        captureStream = ds
  │
  │      混合
  │        micStream  = getUserMedia(...)
  │        sysStream  = getDisplayMedia(...)  ← 同上丢弃视频
  │        AudioContext → micSrc.connect(dest) + sysSrc.connect(dest)
  │        captureStream = dest.stream        ← 单路合并流
  │
  ├─2─ AudioContext ScriptProcessorNode (4096 samples, mono)
  │      onaudioprocess:
  │        Float32 ch → resampleToInt16(ch, ctx.sampleRate, 16000)
  │        → int16ToBase64(pcm16)
  │        → WS send { type:"input_audio_buffer.append", audio: base64 }
  │        → ASR Proxy (4928) WS bridge → DashScope Qwen3-ASR-Flash-Realtime
  │        + push new Float32Array(ch) → pcmChunksRef（本地 PCM 缓存）
  │
  ├─3─ ASR WS 事件:
  │      "conversation.item.input_audio_transcription.text"
  │         → writeLive(text, segStartMs)   → 更新 live bubble
  │      "input_audio_buffer.speech_started"
  │         → 锚定 segStartMs = Date.now() - recordingStart
  │      "conversation.item.input_audio_transcription.completed"
  │         → flushSegment(fullText, segStart, segEnd)
  │
  └─4─ flushSegment():
         pcmChunksRef[startIdx..end] → concatChunks → resampleToInt16 → encodeWav
         if segMs < 300ms → 丢弃
         POST /api/utterances/ingest?meetingId&text&startMs&endMs&autoMode
           Content-Type: audio/wav, Body: WAV bytes
           │
           ├─ fs.writeFileSync → data/segments/<uuid>.wav
           ├─ embedAudio(wavBytes) → POST voiceprint-service:4929/embed
           │    → 192d float32 embedding
           ├─ matchAndAssign(embedding, autoMode):
           │    foreach speaker: score = cosine(emb, centroid)
           │    ≥ 0.75 → 自动归属
           │    0.6~0.75 + autoMode off → needsReview = true
           │    < 0.6 → INSERT 新 speaker "新用户 N"
           ├─ INSERT utterances (id, meeting_id, speaker_id, text, ...)
           ├─ recomputeCentroid(speakerId)
           │    mean(raw_embedding of all utterances for speaker) → L2 normalize
           └─ emitUtterance(meetingId, utteranceEvent)  ← SSE bus
```

### B. SSE 总线（R8）

```
lib/sse-bus.ts（单例）
  globalThis.__sseBus = new EventEmitter()   ← HMR 安全，dev server 重载不丢订阅
  setMaxListeners(200)

写端（ingest route）:
  emitUtterance(meetingId, { utteranceId, speakerId, speakerName,
                              text, confidence, needsReview, startMs, endMs })
    → bus.emit("meeting:<meetingId>", data)

读端（stream route）:
  GET /api/meetings/[id]/stream → ReadableStream (text/event-stream)
    subscribe(meetingId, cb) → bus.on("meeting:<id>", cb)
    req.signal "abort" → unsub + clearInterval + controller.close()
    每 15s → "event: ping\ndata: {}\n\n"
    utterance 到达 → "event: utterance\ndata: <JSON>\n\n"

浏览器（meetings/[id]/page.tsx）:
  meeting.endedAt == null → new EventSource("/api/meetings/<id>/stream")
  "utterance" event → setUtterances(prev => [...prev, item])   去重 by id
  5s 轮询 GET /api/meetings/<id> → 检测 endedAt 非 null → es.close() + 静态化
  自动滚动: bottomRef.scrollIntoView({ behavior:"smooth" }) on utterances.length
```

### C. AI 会议总结（R9）

Agent SDK 使用 `@anthropic-ai/claude-agent-sdk` 的 `query()` + MCP server 模式。

```
用户点击「AI 总结」
  → POST /api/meetings/[id]/summary  (SSE, text/event-stream)
      → agent.ts runSummaryAgent(meetingId)

runSummaryAgent():
  ├─1─ getAgentEnv() — 构造 env 对象（优先级见 D 节）
  ├─2─ getModel()    — 取 model 字符串
  ├─3─ createMeetingMcpServer() — 注册 4 个 MCP 工具（见下）
  ├─4─ loadPastSummaries(dataDir, limit=5)
  │      读 data/agent-memory/meeting_*.md（最近 5 条）
  │      → 拼成 "## 历史会议总结记忆" 段落注入 prompt
  ├─5─ query({ prompt, options: { model, env, mcpServers, allowedTools,
  │              disallowedTools:["Bash","Edit","Write","Read"...],
  │              permissionMode:"dontAsk", persistSession:false } })
  │      → 返回 AsyncIterable<SDKMessage>
  │
  ├─6─ for await msg of agentQuery:
  │      msg.type=="assistant" → content blocks:
  │        { type:"text" }     → yield { type:"text_delta", data:{text} }
  │        { type:"tool_use" } → yield { type:"tool_use", data:{name,input} }
  │      msg.type=="user" → content blocks:
  │        { type:"tool_result" } → yield { type:"tool_result", data:parsed }
  │
  └─7─ finalText 非空 → saveSummaryMemory(meetingId, finalText, dataDir)
             → fs.writeFileSync data/agent-memory/meeting_<id>.md

MCP 工具集（createMeetingMcpServer）:
  get_meeting_transcript(meeting_id)    → utterances JOIN speakers ORDER BY start_ms
  list_speakers()                       → speakers ORDER BY sample_count DESC
  search_speaker_history(speaker_id, limit=20) → 跨会议发言 ORDER BY created_at DESC
  search_past_meetings(query, limit=5)  → utterances WHERE text LIKE "%query%"

前端 SSE 解析（meetings/[id]/page.tsx startSummary()）:
  ReadableStream → reader.read() → 手动拆 "event:\ndata:\n\n" 块
  "text_delta"   → setSummaryText(prev + data.text)
  "tool_use"     → setToolEvents([...ev, {name, input}])   + ToolCallDisplay
  "tool_result"  → 更新对应 ToolCallDisplay.result
  "error"        → setSummaryError(data.error)
```

### D. 配置优先级（R10）

所有涉及外部 API 的配置读取遵循三层优先级：

```
settings 表（用户通过 /settings 页配置）
  > process.env（.env 文件或容器环境变量）
  > 硬编码默认值

具体映射:
  anthropic_api_key    → ANTHROPIC_API_KEY → (YUNWU_API_KEY fallback)
  anthropic_base_url   → ANTHROPIC_BASE_URL → (YUNWU_BASE_URL if YUNWU_API_KEY set)
  anthropic_model      → ANTHROPIC_MODEL   → "claude-sonnet-4-5-20250929"
  agent_system_prompt  → (无 env fallback)  → 内置中文 prompt
  dashscope_api_key    → DASHSCOPE_API_KEY → (asr-proxy.ts 硬编码，待迁移)
```

API 路由安全模式：
```
GET /api/settings
  getAllSettings() → 脱敏：key 字段首4•••尾4 → 返回浏览器
  非 key 字段（model, base_url, system_prompt）原样返回

PATCH /api/settings
  body: { key: value, ... } → setSetting(key, value) → SQLite
  返回 { ok: true }

GET /api/agent/ping
  getAgentEnv() → new Anthropic({ apiKey, baseURL })
  messages.create({ model, max_tokens:1, messages:[{role:"user",content:"ping"}] })
  → { ok: true, model } 或 { ok: false, error }
```

前端 /settings 页安全行为：
- 加载：`apiKeySaved=true`（key 已存），input 保持空，显示"已配置"绿标
- 编辑：用户输入 → `apiKeyChanged=true`
- 保存：仅当 `apiKeyChanged && apiKey` 时才写入；否则跳过 key 字段不覆盖

## 声纹算法

| 步骤 | 实现 |
|------|------|
| 抽特征 | 3D-Speaker CAM++（ModelScope `damo/speech_campplus_sv_zh-cn_16k-common`）→ 192d float32 |
| 匹配 | 余弦相似度，全表扫描（100 角色量级，ms 级） |
| 三档阈值 | ≥0.75 自动归 / 0.6~0.75 待确认（autoMode 决定是否加 needs_review）/ <0.6 新角色 |
| centroid 更新 | `new_centroid = normalize(old × n + new) / (n+1)`；移动 utterance 时双方完整重算 |

## 关键设计决策

| 决策 | 原因 |
|------|------|
| SQLite 不用向量数据库 | 100 角色量级，全表余弦扫描 < 1ms，无需 sqlite-vss |
| SSE bus 用 EventEmitter 单例 | 单进程 Next.js dev server，无需 Redis；globalThis 保证 HMR 安全 |
| AI 总结用文件 memory 不用 DB 表 | 便于直接编辑角色备注；agent-memory/ 同时是 SDK 历史 context 注入点 |
| API key 脱敏在 API 层而非前端层 | 防止 key 通过 XHR response 被 JS 读取后泄露 |
| 系统音频用 `getDisplayMedia(video:true)` | 部分浏览器拒绝 `video:false`；获取后立即 stop video tracks |

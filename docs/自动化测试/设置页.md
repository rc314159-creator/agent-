# 设置页测试

## 功能描述

`/settings` 页面按**功能**分四块独立配置（不是按中转站分），每块有 URL / API Key / Model + 测试按钮：
- 🎤 语音识别 (ASR)
- 🤖 AI 问答 (Agent)
- 👤 声纹服务 (Voiceprint)
- ✨ Embedding（向量检索，预留）

## 代码路径

| 组件 | 路径 |
|------|------|
| 设置页 UI | `web/src/app/settings/page.tsx` |
| settings GET/PATCH（带脱敏） | `web/src/app/api/settings/route.ts` |
| Agent ping | `web/src/app/api/agent/ping/route.ts` |
| ASR ping（WS 握手） | `web/src/app/api/asr/ping/route.ts` |
| Voiceprint health | `web/src/app/api/voiceprint-health/route.ts` |
| Embedding ping | `web/src/app/api/embedding/ping/route.ts` |
| DB schema + R12 migration | `web/src/lib/db.ts` |

## 测试用例

### TC-设置-01：四块独立渲染

**步骤：** 打开 `/settings`

**期望：**
- 标题「⚙️ 设置」
- 4 个 section，每个有图标 + 标题 + 字段 + 「保存」+ 「测试连接」按钮
- Embedding 块加「未启用」灰标 + 说明文字「当前项目不调用 embedding，仅保留配置」

### TC-设置-02：Agent 默认 llmmelon（关键）

**期望：**
- Provider 4 个选项：「llmmelon (推荐)」「云雾中转 (yunwu.ai)」「Anthropic 官方」「自定义」
- **默认选中 llmmelon**（不是 yunwu，不是 Anthropic 官方）
- 默认模型 `claude-haiku-4-5-20251001`
- 默认 base URL `https://llmmelon.cloud/v1`

### TC-设置-03：DB 启动迁移（R12）

**前提：** DB 里旧值 `agent_base_url = https://api.yunwu.ai/v1`, `agent_model = claude-sonnet-4-5-20250929`

**步骤：** 重启 dev server

**期望：**
- `db.ts initDb()` 末尾的 migration 触发
- DB 自动改为：`agent_base_url = https://llmmelon.cloud/v1`, `agent_model = claude-haiku-4-5-20251001`
- 如有 `LLMMELON_API_KEY` env 且 DB 无 `agent_api_key` → 写入
- 用户**改过自定义值**的不动

### TC-设置-04：API Key 脱敏

**步骤：**
```bash
curl -s http://localhost:4927/api/settings | jq '.settings'
```

**期望：**
- `agent_api_key` / `asr_api_key` / `dashscope_api_key` 显示「前 4 字符 + `••••` + 后 4 字符」
- 不能从 GET 拿到完整明文

### TC-设置-05：保存留存 + 不回填明文

**步骤：**
1. 输入 fake key「sk-test-12345678901234567890」
2. 点「保存 Agent 配置」
3. 刷新页面

**期望：**
- PATCH `/api/settings` body `{agent_api_key: "sk-test-..."}` → 200
- 刷新后 input **不回填明文**（避免浏览器 JS 读取）
- 显示「API Key 已配置（绿色标记）」
- placeholder「留空保持不变」
- 不修改 input → 不会被覆盖

### TC-设置-06：四个测试按钮

**步骤：** 分别点四个测试按钮

**期望：**
| 按钮 | 期望返回 |
|------|---------|
| ASR 测试连接 | 绿色「连接成功，延迟 XX ms」 |
| Agent 测试连通性 | 绿色「连接成功，模型回复：OK」 |
| 声纹服务测试 | 绿色「声纹服务正常（ecapa-tdnn）」 |
| Embedding 测试连接 | 绿色「连接成功，向量维度 1536」 |

**失败排查：**
- ASR 401 → DashScope key 错
- Agent 渠道错 → llmmelon key 错 / model id 不在 llmmelon 渠道支持列表
- 声纹 5xx → Docker 容器没起 `docker compose up -d voiceprint-service`
- Embedding 4xx → yunwu key 没 embedding 权限或 model 写错

### TC-设置-07：Provider 切换 + URL normalize

**步骤：** 选「自定义」→ URL 框输入 `https://api.yunwu.ai/v1`

**期望：**
- 下次加载页面时，URL 末尾 `/v1` 被 `stripV1` 函数 strip 后跟 PROVIDERS 比较
- 自动识别为「云雾中转」而不是「自定义」
- 避免相同 URL 不同后缀被识别成两种 provider

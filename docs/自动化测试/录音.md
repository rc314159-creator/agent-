# 录音流程测试

## 功能描述

用户在录音页（`/`）一键开启录音，可选择录音源（麦克风 / 系统音频 / 混合），实时看到 ASR 字幕，每句话停顿后自动归属到声纹角色，停止后会议存档。

## 代码路径

| 组件 | 路径 |
|------|------|
| 录音页 | `web/src/app/page.tsx` |
| 录音源选择 | `web/src/components/AudioSourcePicker.tsx` |
| 麦克风测试条 | `web/src/components/MicrophoneTester.tsx` |
| WAV 编码 | `web/src/lib/wav.ts` |
| ASR WebSocket 代理 | `web/src/asr-proxy.ts` |
| 切句上传 | `web/src/app/api/utterances/ingest/route.ts` |
| 声纹匹配 | `web/src/lib/match.ts` |
| 创建会议 | `web/src/app/api/meetings/route.ts` |

## 测试用例

### TC-录音-01：一键直录（最关键 UX）

**步骤：**
1. 打开 `http://localhost:4927/`
2. 点紫色「🎤 开始录音」按钮
3. 浏览器弹麦克风权限 → 允许
4. 等 3 秒

**期望：**
- 点击后**立即**进入录音状态（不打开任何 setup 面板）
- 显示红色「⬜ 停止录音」+ 计时器 `00:00:0X` + 「● 麦克风」指示
- 状态条：「录音中: 会议 YYYY/M/D HH:MM:SS — 麦克风」
- 不需要二次确认

**失败排查：**
- 点击后只展开 setup 面板 = 旧版 2 步流程未升级，查 page.tsx 的 `<button onClick={...}>` 是否绑定 `startRecording` 而非 `setShowSetup`
- 麦克风权限被拒 → 状态条变红色 + 警告

### TC-录音-02：录音源选择 disclosure

**步骤：**
1. 录音页未录状态
2. 点「▸ 麦克风」灰色小按钮

**期望：**
- 折叠面板展开，显示三模式卡片（麦克风/系统音频/混合）+ 设备 dropdown + 实时电平条
- 选择会持久化到 localStorage `vp:audioMode` / `vp:micDeviceId`
- 下次刷新自动套用上次选择

### TC-录音-03：系统音频模式

**步骤：**
1. 展开 disclosure → 选「系统音频」
2. 点开始录音

**期望：**
- 浏览器弹原生 tab 选择框
- 选择标签页 + 勾选「分享音频」→ 录音开始
- 顶部状态条变「— 系统音频」
- getDisplayMedia 返回的 video track 应被立即 stop（不要画面，只要音频）

### TC-录音-04：混合模式

**步骤：**
1. 选「混合」→ 开始录音

**期望：**
- 同时获取 getUserMedia (mic) + getDisplayMedia (sys audio)
- AudioContext.createMediaStreamDestination() 合并为单流
- 录音 PCM 包含两路混音

### TC-录音-05：ASR 实时字幕

**前提：** 真实麦克风（不是 Playwright fake device）

**步骤：**
1. 开始录音
2. 说话 5 秒，停顿

**期望：**
- 「讲话中」气泡实时滚动文字（部分识别中）
- 停顿 ≥400ms 后气泡变「归属中…」
- 1-2 秒内归属到角色（如「张三」或「新用户 N」）+ 匹配 X% 显示

**失败排查：**
- 字幕不出 → asr-proxy 日志 `tail logs/asr-proxy.log` 看 DashScope 是否报错
- 归属永远「归属中…」→ voiceprint service 4929 是否健康，或 ingest API 5xx

### TC-录音-06：停止录音

**步骤：**
1. 录音中点「停止录音」

**期望：**
- 计时停止
- WS 关闭，asr-proxy 日志显示 `client closed`
- 状态条「已停止。会议已归档，可到历史会议查看」
- `data/vp.db` 里 `meetings` 表对应行的 `ended_at` 被填充

### TC-录音-07：自动模式开关

**步骤：**
1. 不勾选「自动模式」
2. 录一段 ASR 匹配相似度 0.6-0.75 的话

**期望：**
- 该 utterance 标 `needs_review = 1`，UI 显示黄色三角警告 + 「确认/移到」按钮
- 勾选自动模式 → needs_review = 0，直接归属

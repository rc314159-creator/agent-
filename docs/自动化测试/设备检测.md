# 设备检测页测试

## 功能描述

`/check` 模拟在线笔试设备自检：麦克风 / 摄像头 / 系统音频 / 扬声器 / 后端服务 5 项独立测试，进开会前一次性过一遍。

## 代码路径

| 组件 | 路径 |
|------|------|
| 设备检测页 | `web/src/app/check/page.tsx` |
| nav 入口 | `web/src/components/nav.tsx`（「设备检测」tab） |
| 后端 ping 端点 | 同设置页测试 |

## 测试用例

### TC-检测-01：麦克风（5 秒录音 + 电平 + 回放）

**步骤：** 选择麦克风设备 → 点「测试 5 秒」

**期望：**
- 调 `navigator.mediaDevices.getUserMedia` 弹权限
- 绿色电平条实时动画
- 5 秒后自动停 + 显示「峰值 X%」
- 录音回放 `<audio controls>` 出现
- 峰值 < 3% → 红色 FAIL「没听到任何声音」
- 峰值 < 15% → 黄色 WARN「输入信号偏弱」
- 峰值 ≥ 15% → 绿色 PASS

### TC-检测-02：摄像头预览

**步骤：** 选摄像头 → 点「开启预览」

**期望：**
- getUserMedia({video: true}) 弹权限
- `<video>` 元素显示实时画面
- 「关闭」按钮可点
- 隐私：关闭后 track 被立即 stop

### TC-检测-03：系统音频检测

**步骤：** 点「测试系统音频」

**期望：**
- getDisplayMedia 弹原生 tab 选择框
- 用户**勾选「分享音频」** → 5 秒后自动停 + 「系统音频抓取成功」
- 用户**没勾**「分享音频」→ 黄色 WARN「已分享标签页但未勾选音频」
- 用户取消 → 红色「用户取消或不支持」

### TC-检测-04：扬声器测试音

**步骤：** 点「播放测试音」

**期望：**
- AudioContext 440Hz sin 波，gain 0.2，播放 2 秒
- 状态条「正在播放 440Hz 测试音 2 秒…」→ 完成「已播放，请人耳确认」

### TC-检测-05：一键测后端

**步骤：** 顶部紫色「一键测后端服务」

**期望：**
- 三块同时触发：ASR / Agent / Voiceprint
- 每块独立显示 loading → ok/error
- ASR 显示延迟（ms）
- Agent 显示模型回复字符
- Voiceprint 显示模型名（ecapa-tdnn）
- 失败时显示 error 详情

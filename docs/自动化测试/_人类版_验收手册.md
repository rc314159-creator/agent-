# 人类验收手册（5 分钟跑完）

> 简短版：只说"做什么"，不解释原理。AI 详细版在同目录其它 md 文件。
>
> 用法：每次发版前按本手册逐条走，全过 = 可发布。

---

## 一、起前置服务（30 秒）

```bash
docker compose up -d voiceprint-service          # 4929
cd web && npm run asr-proxy &                    # 4928
cd web && npm run dev                            # 4927
```

浏览器开 http://localhost:4927/

---

## 二、设备自检（1 分钟）

进 「设备检测」tab：

| 操作 | 应该看到 |
|------|---------|
| 麦克风 → 测试 5 秒，说话 | 绿色 PASS「麦克风正常（峰值 XX%）」 |
| 摄像头 → 开启预览 | 看到自己 |
| 系统音频 → 测试系统音频 | 浏览器弹窗 → 选 tab + 勾「分享音频」→ 绿色 PASS |
| 扬声器 → 播放测试音 | 听到「嘟——」2 秒 |
| 一键测后端服务 | ASR / Agent / 声纹 三个全绿 |

任一红色 / 黄色 → 看页面提示修，常见：mic 权限被拒 / Docker 没起 / API key 没配。

---

## 三、录音 → ASR → 声纹归属（2 分钟）

1. 进 「录音」tab
2. 点紫色「🎤 开始录音」（**一次**，不用打开任何面板）
3. 说话 30 秒以上（**真人**，fake-device 出不来字幕）
4. 应该看到：
   - 字幕实时滚动（「讲话中」气泡灰色）
   - 每句话停顿 ≈1 秒 → 气泡变彩色（角色名 + 匹配 %）
   - 第一次说话 → 「新用户 1」
   - 同一人再说话 → 仍归到「新用户 1」（匹配 % > 75）
5. 点红色「停止录音」
6. 状态条「已停止。会议已归档」

---

## 四、会议详情 + AI 问答（1 分钟）

进 「历史会议」tab，点最新会议：

| 操作 | 应该看到 |
|------|---------|
| 左栏 utterance 时间线 | 每句话一个气泡，带角色名 + 时间 |
| 右栏 AI 问答面板 | 「显示推荐问题」按钮 |
| 点「显示推荐问题」 | 4 个 chip：帮我总结 / 列待办 / 分析发言 / 关键决策 |
| 点「帮我总结」 | 流式输出，AI 用具体角色名（"张三"而不是"说话人 1"） |
| 顶部「下载记录」 | 下载 `.md`，内容是 `[角色名 hh:mm:ss] 文字` |
| 顶部「下载对话」 | 下载 `.md`，AI 问答历史 |

---

## 五、声纹库（30 秒）

进 「声纹库」tab：

| 操作 | 应该看到 |
|------|---------|
| 看角色列表 | 「新用户 1」N 段样本 |
| 顶部如有红/黄 banner「检测到 N 对可能重复」 | 点击「合并到」一键合并 |
| 进任一角色详情 | 改名 / 移动 utterance / 播放音频 |
| 红色「删除」按钮 | 二次确认 → 角色 + 所有发言 + 音频一起删 |

---

## 六、设置（30 秒）

进 「设置」tab：

| 块 | 应该有 |
|----|--------|
| 🎤 ASR | DashScope Key + WS URL + 「测试连接」按钮 |
| 🤖 AI 问答 (Agent) | Key + Provider（默认 llmmelon 推荐）+ 模型（haiku-4-5）+ System Prompt + 「测试连通性」 |
| 👤 声纹服务 | URL（默认 localhost:4929）+ 「测试声纹服务」 |
| ✨ Embedding（预留） | 默认云雾 + text-embedding-3-small + 「测试连接」 |

每块「测试」按钮都点一次，全绿色 PASS。

---

## 七、异常处理（验证韧性，可选）

| 操作 | 应该看到 |
|------|---------|
| 录音中拔网线 30 秒后插回 | 红色「⚠️ ASR 已断开」banner → 网回来后 4 秒内自动恢复（绿） |
| 录音 30 分钟 | DashScope 可能 1011 关闭 → proxy 自动重连 → UI 透明 |

---

## 失败时怎么找责任

任一项 FAIL：
1. 截图 + 浏览器 console 错误
2. `tail -50 logs/asr-proxy.log` + `tail -50 logs/next-dev.log`
3. 对应模块详细测试套件：见 `docs/自动化测试/<功能>.md`（AI 详细版）

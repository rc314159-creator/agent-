# 声纹算法测试

## 功能描述

R14 声纹算法 v2：音频质量门槛 + 三档阈值 + margin 决策 + outlier σ-score + 加权 centroid + 重复检测。

## 代码路径

| 组件 | 路径 |
|------|------|
| 算法主体 | `web/src/lib/match.ts` |
| ingest 调用 | `web/src/app/api/utterances/ingest/route.ts` |
| 重复检测端点 | `web/src/app/api/speakers/duplicates/route.ts` |
| Spec | `docs/功能模块/声纹算法.md` |

## 测试用例（AI 可独立跑）

### TC-声纹算法-01：audioQualityGate 拦静音

```bash
# 准备：1 秒纯静音 WAV（44 字节 RIFF header + 32000 字节零字节）
python3 -c "
import struct
header = b'RIFF' + struct.pack('<I', 36 + 32000) + b'WAVE'
header += b'fmt ' + struct.pack('<IHHIIHH', 16, 1, 1, 16000, 32000, 2, 16)
header += b'data' + struct.pack('<I', 32000)
import sys; sys.stdout.buffer.write(header + b'\\x00' * 32000)
" > /tmp/silent1s.wav

curl -s -X POST "http://localhost:4927/api/utterances/ingest?meetingId=test-r9" \
  -H "Content-Type: audio/wav" \
  --data-binary @/tmp/silent1s.wav
```

**期望**：
```json
{"skipped":true,"reason":"近乎静音 (RMS=0 < 100)","rms":0,"zcr":0}
```

**失败排查**：
- 返回 `{utteranceId:"...",speakerId:"...",isNewSpeaker:true}` = quality gate 没生效，看 ingest/route.ts 的 audioQualityGate 调用顺序
- 返回 `{"error":"audio too short"}` = 改用 ≥ 1 秒的 WAV

### TC-声纹算法-04：margin 决策

**前提**：库里有 ≥2 个 speaker centroid 都跟新 embedding 接近。

**期望**：matchAndAssign 返回 `needsReview:true`（margin < 0.05 时即便 top1 ≥ 0.75 也会标 review）。

无法纯 curl 跑（要构造 embedding 邻居）。**人类测试**：
1. 真录两人轮流说话各几句
2. 找一个匹配率 ~78%、margin 跟另一个 speaker 也 ~77% 的 utterance
3. 看是否被标了 needs_review

### TC-声纹算法-05：重复检测端点

```bash
curl -s "http://localhost:4927/api/speakers/duplicates?threshold=0.85" | jq -c
```

**期望**：

threshold 越低 → pairs 越多。

### TC-声纹算法-06：merge 合并

```bash
# 准备：找两个真实存在的 speaker id
A=<sourceId>
B=<targetId>

curl -s -X PATCH "http://localhost:4927/api/speakers/$A" \
  -H "Content-Type: application/json" \
  -d "{\"mergeIntoId\":\"$B\"}" | jq -c

# 验证：
sqlite3 data/vp.db "SELECT id FROM speakers WHERE id='$A'"   # → 空（已删）
sqlite3 data/vp.db "SELECT COUNT(*) FROM utterances WHERE speaker_id='$B'"  # → 增加了 A 的 utt 数
```

**期望**：`{"ok":true,"mergedInto":"<B>"}`

### TC-声纹算法-07：DELETE 角色（cascade）

```bash
ID=<test speaker id>
# 没 utterance → 默认 OK
curl -s -X DELETE "http://localhost:4927/api/speakers/$ID" | jq -c
# 期望: {"ok":true,"deletedUtterances":0}

# 有 utterance 默认拒绝
curl -s -X DELETE "http://localhost:4927/api/speakers/$ID" | jq -c
# 期望: HTTP 409 {"error":"...还有 N 条发言..."}

# cascade 一起删
curl -s -X DELETE "http://localhost:4927/api/speakers/$ID?cascade=1" | jq -c
# 期望: {"ok":true,"deletedUtterances":N}

# 验证 wav 文件物理删除
ls data/segments/ | wc -l   # 应该减少 N 个
```

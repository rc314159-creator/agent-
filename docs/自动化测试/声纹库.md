# 声纹库测试

## 功能描述

`/voiceprints` 列表 + `/voiceprints/[id]` 详情：浏览所有 speaker / 改名 / 移动 utterance / **删除角色（cascade 一起删 utterances 和音频）** / 播放音频样本。

## 代码路径

| 组件 | 路径 |
|------|------|
| 列表页 | `web/src/app/voiceprints/page.tsx` |
| 详情页 | `web/src/app/voiceprints/[id]/page.tsx` |
| 列表 API | `web/src/app/api/speakers/route.ts` |
| 详情/改名/合并/删除 API | `web/src/app/api/speakers/[id]/route.ts` |
| utterance 移动 | `web/src/app/api/utterances/[id]/route.ts` |
| centroid 重算 | `web/src/lib/match.ts` `recomputeCentroid` |

## 测试用例

### TC-声纹-01：列表渲染

**步骤：** 打开 `/voiceprints`

**期望：**
- 卡片网格，每个 speaker 一张卡：名字 + 样本数
- 点击进入详情

### TC-声纹-02：改名

**步骤：** 详情页 → 点「改名」→ 输入「张三」→ 回车

**期望：**
- PATCH `/api/speakers/<id>` body `{name: "张三"}` → 200
- UI 立即显示新名
- `data/vp.db` `speakers.name` 字段更新
- centroid 不变（改名只改 name）

### TC-声纹-03：移动 utterance

**步骤：** 详情页选一条 utterance → 「移到」dropdown → 选另一个 speaker

**期望：**
- PATCH `/api/utterances/<id>` body `{speakerId: "..."}` → 200
- 两个 speaker 的 centroid 都用 `recomputeCentroid` 重算（基于 raw_embedding）
- UI 上 utterance 从当前列表消失

### TC-声纹-04：删除空角色（无 utterance）

**步骤：**
1. 创建一个无 utterance 的 speaker（测试用）
2. 详情页点红色「删除」按钮 → 确认对话框

**期望：**
- 确认对话框「确认删除角色「<name>」？此操作不可撤销。」
- 点确认 → DELETE `/api/speakers/<id>` → 200 `{ok:true,deletedUtterances:0}`
- 跳转回 `/voiceprints` 列表
- 列表中该 speaker 消失

### TC-声纹-05：删除带 utterance 的角色（cascade，关键）

**步骤：**
1. 详情页有 utterance 的 speaker（如「新用户 22」）
2. 点红色「删除」按钮

**期望：**
- 对话框：「确认删除角色「<name>」？该角色下还有 N 条发言，将一同删除（音频文件也会删除）。此操作不可撤销。」
- 点确认 → DELETE `/api/speakers/<id>?cascade=1` → 200 `{ok:true,deletedUtterances:N}`
- `data/segments/<uuid>.wav` 文件被物理删除
- utterances 表对应行 DELETE
- speakers 表对应行 DELETE
- 跳转回 `/voiceprints`

**失败排查：**
- 没 cascade 返回 409 `{error:"...还有 N 条发言..."}` —— 这是为防误删，UI 应自动加 cascade=1 才请求

### TC-声纹-06：合并角色

**步骤：** PATCH /api/speakers/<id> body `{mergeIntoId: "<target>"}`

**期望：**
- 所有 utterance 的 speaker_id 改为 target
- 当前 speaker 行删除
- target 的 centroid `recomputeCentroid` 重算

### TC-声纹-07：播放音频样本

**步骤：** 详情页 → 某个 utterance → 点「播放」

**期望：**
- HTMLAudioElement 加载 `/data/segments/<uuid>.wav`
- 播放期间按钮显示「⏸」
- 播放完毕 / 再次点击 → 暂停

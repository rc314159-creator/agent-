# 会议详情页测试

## 功能描述

`/meetings/[id]` 页面：左栏展示 utterance 时间线（角色名 + 时间 + 匹配 % + 文本），右栏 AI 问答 chat 面板。录音中通过 SSE 实时追加新 utterance，结束后变静态。

## 代码路径

| 组件 | 路径 |
|------|------|
| 详情页 | `web/src/app/meetings/[id]/page.tsx` |
| 会议元数据 + utterance API | `web/src/app/api/meetings/[id]/route.ts` |
| SSE 实时字幕端点 | `web/src/app/api/meetings/[id]/stream/route.ts` |
| SSE 总线（HMR 安全单例） | `web/src/lib/sse-bus.ts` |
| ingest 触发 emit | `web/src/app/api/utterances/ingest/route.ts` |

## 测试用例

### TC-详情-01：基本渲染

**步骤：**
```bash
# 先确保有数据
curl -s http://localhost:4927/api/meetings/test-r9 | jq '.utterances | length'
```

**期望：**
- HTTP 200，返回 `{ meeting: {...}, utterances: [...] }`
- 浏览器打开 `/meetings/test-r9`：标题「测试会议 R9」+ 「2 句·开始于 ...」+ 张三 00:00 和 00:04 两条 utterance
- 顶部「下载记录」+「下载对话」按钮可见

### TC-详情-02：SSE 流式实时

**步骤：**
1. 开始一段新录音
2. 打开新 tab 进 `/meetings/<新 meeting id>`

**期望：**
- 页面显示「● 录音中」红点 + 「实时字幕接收中…」spinner
- 新 utterance ingest 后 1 秒内出现在列表
- EventSource 自动监听 `/api/meetings/<id>/stream`
- 15 秒一次 ping 防止 idle 关闭

### TC-详情-03：录音结束自动断 SSE

**步骤：**
1. 录音中查看详情页（在录音）
2. 录音页点停止
3. 详情页等 5-10 秒

**期望：**
- 5 秒轮询检测到 `meeting.endedAt !== null`
- EventSource close（看 DevTools Network 标签）
- 「● 录音中」红点消失
- 静态显示完整对话流

### TC-详情-04：角色色块映射

**期望：**
- 每个 speaker 拿到固定颜色（蓝/绿/黄/粉/紫/青/红/酸橙循环）
- 同一 speaker 不同 utterance 颜色一致
- 「归属中…」「讲话中」用灰色

### TC-详情-05：needs_review 标记

**期望：**
- 匹配置信度 0.6-0.75 且非自动模式的 utterance 用黄色边框
- 显示警告三角图标
- 提供「确认 / 移到他人」按钮

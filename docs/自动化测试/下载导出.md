# 下载导出测试

## 功能描述

会议详情页顶部两个按钮：
- 「下载记录」→ `/api/meetings/[id]/transcript.md`：会议元信息 + `[角色名 hh:mm:ss] text` 行
- 「下载对话」→ `/api/meetings/[id]/chat.md`：AI 问答历史 markdown。**如果 chat 历史为空，自动跑一次默认总结再返回**

## 代码路径

| 组件 | 路径 |
|------|------|
| transcript.md | `web/src/app/api/meetings/[id]/transcript.md/route.ts` |
| chat.md（含 auto-summary） | `web/src/app/api/meetings/[id]/chat.md/route.ts` |
| Chat agent | `web/src/lib/agent.ts` `runChatAgent()` |

## 测试用例

### TC-下载-01：transcript.md 格式

**步骤：**
```bash
curl -s "http://localhost:4927/api/meetings/test-r9/transcript.md" -i
```

**期望：**
- HTTP 200
- `Content-Type: text/markdown; charset=utf-8`
- `Content-Disposition: attachment; filename*=UTF-8''<encoded 中文文件名>.md`
- Body 格式：
  ```
  # 会议记录 — <title>

  **开始时间：** ...
  **结束时间：** ...
  **参与者：** 张三, 李四

  ---

  [张三 00:00:00] 文字
  [张三 00:00:04] 文字
  ```

### TC-下载-02：chat.md（有历史）

**步骤：**
```bash
# 先确保 test-r9 有 chat 历史
curl -s "http://localhost:4927/api/meetings/test-r9/chat.md" | head -20
```

**期望：**
- HTTP 200 + 正确 Content-Disposition
- Body 含「**用户：** ...」+「**AI：**\n...」分隔，按时间顺序

### TC-下载-03：chat.md 空历史自动总结（关键修复）

**前提：** 一个新会议有 utterance 但没有任何 chat 历史

**步骤：**
```bash
# 准备：插入测试会议 + utterance（无 chat）
sqlite3 /Users/rencan/product/data/vp.db "
INSERT OR REPLACE INTO meetings (id, title, started_at, ended_at) VALUES ('test-empty-chat', '空对话测试', $(date +%s%3N), $(date +%s%3N));
INSERT OR REPLACE INTO utterances (id, meeting_id, speaker_id, text, start_ms, end_ms, confidence, needs_review, created_at) VALUES ('utt-tec-1', 'test-empty-chat', 'spk-r9', '今天讨论的是 R12 的设备检测功能', 0, 3000, 0.9, 0, $(date +%s%3N));
"

# 触发下载（会自动跑总结，需 5-15 秒）
curl -s "http://localhost:4927/api/meetings/test-empty-chat/chat.md" | head -30

# 清理
sqlite3 /Users/rencan/product/data/vp.db "DELETE FROM meeting_chats WHERE meeting_id='test-empty-chat'; DELETE FROM utterances WHERE meeting_id='test-empty-chat'; DELETE FROM meetings WHERE id='test-empty-chat';"
```

**期望：**
- HTTP 200，**Body 不为空**（不是只有标题 + 时间）
- 自动生成的总结写入 `meeting_chats` 表（再次 curl 也能直接取到）
- 总结里出现「R12」「设备检测」等关键词

**失败排查：**
- Body 只有标题 = chat.md route 没接 auto-summary，看 route.ts 是否在 messages 为空时调 runChatAgent
- 触发但卡住 = Agent ping 不通，看 /api/agent/ping
- 返回 500 = TypeScript 编译错误，看 dev log

### TC-下载-04：中文文件名编码

**步骤：** 浏览器右键「另存为」（不是 curl）

**期望：**
- 保存对话框默认文件名是「会议记录-测试会议 R9.md」/「AI对话-测试会议 R9.md」（解码后）
- Content-Disposition 用 `filename*=UTF-8''<percent-encoded>` RFC 5987 兼容

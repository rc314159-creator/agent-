# 开发计划: MeetFlow 群面记录助手

## 背景
用户技术背景，即将参加多场线上产品群面。需要一个美观且功能丰富的 Web 工具辅助担任记录员角色。通过共享屏幕展示工具，展示技术差异化优势，同时对产品讨论产生实际帮助。

## 目标
做出一个完整可用的线上群面记录助手 Web 应用：
1. 核心记录画布：支持大纲、思维导图、白板、模板四种模式
2. 语音录音系统：实时语音转文字 + 说话人标注
3. AI 辅助功能：总结、检索、问答、自动填充 + AI 对话侧边栏
4. 所有 AI 功能支持全局开关（适应不允许 AI 的面试场景）
5. 视觉极致美观，深色主题，面试共享屏幕时给人专业印象

## 验收标准
1. 访问 http://localhost:4927 页面正常加载，无报错
2. 四种画布模式均可正常切换和使用，无 ChunkLoadError
3. 录音按钮可点击，波形可视化正常显示
4. Mock 转录文本带说话人颜色标注，可滚动可复制
5. AI 对话侧边栏可打开，可发消息，Mock 回复正常
6. AI 全局开关生效：关闭后所有 AI 元素隐藏
7. 所有按钮可点击，无遮挡/重叠
8. 面板可拖拽调节大小
9. 键盘快捷键 1/2/3/4 切换画布模式，⌘/ 打开 AI

## 技术栈（已讨论确定）

| 层 | 选型 |
|---|---|
| 框架 | Next.js 16 + TypeScript |
| UI | shadcn/ui (base-ui) + Tailwind CSS |
| 富文本编辑器 | contentEditable (后续升级 Plate) |
| 思维导图 | simple-mind-map (vanilla JS, React 封装) |
| 白板 | @excalidraw/excalidraw (React 组件) |
| 音频可视化 | WaveSurfer.js Record Plugin |
| 动画 | Framer Motion |
| ASR（后续） | 阿里云 DashScope Qwen3-ASR-Flash-Realtime (WebSocket) |
| LLM（后续） | 云物中转 → Claude Sonnet 4.5 |

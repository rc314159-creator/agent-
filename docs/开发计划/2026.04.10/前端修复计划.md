# MeetFlow 前端修复与功能完善计划

## 问题总览

当前前端存在 1 个 Critical 错误、5 个功能未完成项、2 个代码质量问题。

## 修复任务

### T1 — [Critical] ProjectPanel 嵌套 button 导致 Hydration Error

**文件**: `src/components/layout/ProjectPanel.tsx:163-206`
**问题**: 外层 `<button>` 内嵌套了 `<Button>` 组件（渲染为 `<button>`），违反 HTML 规范，导致 hydration error
**方案**: 将外层 `<button>` 改为 `<div>`，保留 onClick 和样式，添加 `role="button"` + `tabIndex={0}` + `onKeyDown` 保持可访问性

### T2 — [High] VoicePanel 初始 Mock 数据替换

**文件**: `src/components/voice/VoicePanel.tsx:17,95,498`
**问题**: 
- 初始 transcripts 使用 `mockTranscripts`（应为空数组）
- SummaryDialog 传入 `mockSummary`（应使用 AI 实时生成）
**方案**: 
- 初始 `transcripts` 改为 `[]`
- 一键总结改为调用 `/api/ai` 实时生成，结果传给 SummaryDialog
- SummaryDialog 改为接收动态内容，移除硬编码的 actionItems/keyPoints

### T3 — [High] SummaryDialog 动态化

**文件**: `src/components/voice/SummaryDialog.tsx:20-31`
**问题**: `actionItems` 和 `keyPoints` 硬编码，与实际内容无关
**方案**: 
- 从 summary 文本中解析结构化内容（或直接展示 markdown）
- 移除静态数组，改为 props 传入或从 summary 解析

### T4 — [High] AIPanel Mock 搜索结果替换

**文件**: `src/components/ai/AIPanel.tsx:24,35,131-141`
**问题**: 信息检索 Tab 使用 `mockSearchResults`，搜索只是本地过滤 mock 数据
**方案**: 将搜索功能改为调用 `/api/ai` 进行真实信息检索，或标注为"示例数据"并提供说明

### T5 — [Medium] Header 占位按钮功能实现

**文件**: `src/components/layout/Header.tsx:87-110`
**问题**: 分享、下载、设置按钮无 onClick 处理
**方案**: 
- 下载：导出当前画布+转录内容为 Markdown 文件
- 分享/设置：添加 toast 提示"功能开发中"

### T6 — [Medium] Sidebar 占位按钮功能实现

**文件**: `src/components/layout/Sidebar.tsx:116-128`
**问题**: 历史记录、导出按钮无 onClick 处理
**方案**: 添加 toast 提示"功能开发中"

### T7 — [Medium] AI Route 非流式响应状态码转发

**文件**: `src/app/api/ai/route.ts:39-41`
**问题**: 非流式响应不转发上游 HTTP 状态码
**方案**: 添加 `status: res.status` 到 Response 构造

### T8 — [Low] useProject saveField 竞态修复

**文件**: `src/hooks/useProject.ts:123-138`
**问题**: setTimeout 回调中捕获的 `currentProjectId` 可能已过期
**方案**: 在 setTimeout 内部通过 ref 读取最新的 currentProjectId

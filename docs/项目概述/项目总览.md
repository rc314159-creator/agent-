# 项目总览

## 项目名称

Auto-Picture / MeetFlow（群面记录助手）

## 项目背景

产品经理群面场景的在线记录工具。面试官在线上共享屏幕，展示工具的使用能力。工具需要展现画布编辑、语音记录、AI 辅助等技术能力，体现技术差异化。

## 项目目标

1. 多模式画布编辑：大纲、思维导图、白板、模板（SWOT 等）
2. 实时语音记录：基于阿里云 DashScope Qwen3-ASR 的语音识别
3. AI 辅助分析：侧边栏对话 + 底部快捷面板
4. 美观的 UI 和流畅的交互体验
5. 一键共享屏幕展示

## 技术栈

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 框架 | Next.js | 16.2.3 | React 全栈框架 |
| UI | React | 19.2.4 | 前端视图层 |
| 组件库 | shadcn/ui + Tailwind | 4.x | 设计系统 |
| 动画 | framer-motion | 12.x | 页面动效 |
| 白板 | Excalidraw | 0.18.x | 画布绘图 |
| 思维导图 | simple-mind-map | 0.14.x | 思维导图渲染 |
| 音频 | WaveSurfer.js | 7.x | 音频波形可视化 |
| ASR | DashScope Qwen3-ASR | - | 实时语音识别 |
| LLM | 云雾中转 | - | AI 对话能力 |
| 语言 | TypeScript | 5.x | 类型安全 |

# 运行环境

## 开发环境

| 项目 | 要求 |
|------|------|
| Node.js | >= 18 |
| 包管理器 | npm (lockfile: package-lock.json) |
| 端口 | 4927 (dev server) |

### 启动方式

```bash
cd web
npm install
npm run dev          # http://localhost:4927
```

### 构建

```bash
npm run build
npm start
```

# 声纹归属算法 v2

## 一、总体管线

```
WAV (16kHz mono 16bit)
  │
  ▼
audioQualityGate() ── 拒 ──► 返回 skipped:true（不创建 speaker）
  │ pass
  ▼
3D-Speaker ECAPA /embed  ──► 192d Float32 embedding (L2-normalized)
  │
  ▼
matchAndAssign()
  ├─ cos(emb, centroid_i) for all i
  ├─ sort desc, take top1 / top2
  ├─ margin = top1 - top2
  ├─ outlierZ = (mean_self - top1) / std_self    # 偏离 top1 历史几个 σ
  └─ 决策表（见下）
  │
  ▼
INSERT utterance(raw_embedding, confidence=top1, needs_review, ...)
  │
  ▼
recomputeCentroid(speakerId)
  └─ weighted_mean(embeddings × confidence × time_decay)  + L2 normalize
```

## 二、关键算法

### 2.1 音频质量门槛 `audioQualityGate(wav)`

代码：`web/src/lib/match.ts` `audioQualityGate`

```ts
if (wav.length < 44 + 16_000) reject("片段太短 (< 0.5s)");
// 解码 int16 PCM
const rms = sqrt(sum(s²) / N);
const zcr = zeroCrossings / N;
if (rms < 100)              reject("近乎静音");
if (zcr < 0.005 || zcr > 0.6) reject("ZCR 异常 (非人声)");
```

| 指标 | 含义 | 阈值 | 拒绝原因 |
|------|------|------|---------|
| RMS | 均方根能量 | < 100 (int16 量级) | 近乎静音 |
| ZCR | 零交叉率 | < 0.005 (纯单频) 或 > 0.6 (白噪声) | 非人声 |
| 时长 | PCM 样本数 ÷ 采样率 | < 0.5 秒 | 段太短，ECAPA 不可靠 |

**为什么这样**：纯静音 / sin 波 / 噪声会被 ECAPA 映射到聚类附近的某点，反复触发"新用户 N"。门槛挡住后该段直接 `{skipped:true}` 返回，不入 utterance 表也不创建 speaker。

### 2.2 三档阈值 + margin 决策 `matchAndAssign(emb, autoMode)`

代码：`web/src/lib/match.ts`

| top1 cosine | margin (top1-top2) | outlierZ | 结果 |
|-------------|--------------------|---------:|------|
| ≥ 0.75 | ≥ 0.05 | ≤ 2σ | **High**：自动归属，needsReview=false |
| ≥ 0.75 | < 0.05 (相邻 speaker 接近) | — | **Ambiguous**：归 top1，但 needsReview=!autoMode |
| ≥ 0.75 | ≥ 0.05 | > 2σ (outlier) | **Outlier**：归 top1，但 needsReview=!autoMode |
| [0.60, 0.75) | — | — | **Medium**：归 top1，needsReview=!autoMode |
| < 0.60 | — | — | **Low**：新建 `新用户 N` |

**为什么加 margin**：原 v1 只看 top1 score，但如果两个 speaker 都很像（top1=0.78 top2=0.77），归 top1 实际是赌博。加 margin ≥ 0.05 才放行 High 档自动归属。

**为什么加 outlier**：top1 高分但和 top1 自己历史样本距离也远（> 2σ），说明这条 embedding 偏，可能是噪音段或新说话风格。standard error 2σ 是常用阈值。

### 2.3 加权 centroid `recomputeCentroid(speakerId)`

代码：`web/src/lib/match.ts`

```ts
weight(u) = clamp(u.confidence, 0.3, 1.0) × 2^(-age_days / 30)
centroid = (Σ u.embedding × weight(u)) / Σ weight(u)
centroid /= |centroid|   // L2 normalize
```

| 因子 | 含义 | 范围 | 为什么 |
|------|------|------|--------|
| confidence | 归属时的 cosine 分数 | [0.3, 1.0] | 低置信度样本权重打折，避免毒化均值；高分也不无限放大 |
| time decay | 半衰期 30 天的指数衰减 | (0, 1] | 用户声音/麦克风缓慢漂移，旧样本权重逐步下降 |

**为什么 idempotent**：仍然是「全量重算」而非 EMA 滚动更新。用户每次移动 utterance、改名都安全调用，不会累积浮点误差。

### 2.4 重复检测 `findDuplicateSpeakers(threshold=0.85)`

代码：`web/src/lib/match.ts` + `web/src/app/api/speakers/duplicates/route.ts`

```ts
for (i, j) in C(n, 2):
  if cos(centroid_i, centroid_j) >= 0.85:
    emit { aId, aName, bId, bName, similarity }
```

UI 入口：`/voiceprints` 顶部 banner 显示「检测到 N 对可能重复，是否合并？」+ 一键 merge。

**为什么 0.85**：实测 ECAPA 同一人不同句子余弦在 0.7-0.9，不同人在 0.3-0.6。0.85 是同一人的下沿，能触发"这两个 speaker 多半是同一人误分"。用户人工最终决策合或者不合。

## 四、可调参数（汇总）

写在 `web/src/lib/match.ts` 顶端 `export const ...` 区域：

| 常量 | 默认 | 含义 |
|------|------|------|
| HIGH_THRESHOLD | 0.75 | High 档下沿 |
| LOW_THRESHOLD | 0.60 | Medium 档下沿（再低就新建） |
| MARGIN_THRESHOLD | 0.05 | top1 vs top2 最小差距才允许 High 自动归属 |
| OUTLIER_SIGMA | 2.0 | 偏离 top1 自身样本几个 σ 算 outlier |
| TIME_HALF_LIFE_DAYS | 30 | centroid 时间衰减半衰期 |
| MIN_CONF_WEIGHT | 0.3 | 置信度权重下限（即便低分也要算一点） |
| MAX_CONF_WEIGHT | 1.0 | 置信度权重上限（防过分放大） |
| audioQualityGate RMS | 100 | int16 量级，低于此当静音 |
| audioQualityGate ZCR 下限 | 0.005 | 纯单频检测 |
| audioQualityGate ZCR 上限 | 0.6 | 白噪声检测 |
| findDuplicateSpeakers 阈值 | 0.85 | centroid 相似度判定可能重复 |

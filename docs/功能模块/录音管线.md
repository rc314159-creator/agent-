# 录音管线

## 一、总体数据流

```
浏览器
 ├─ getUserMedia / getDisplayMedia → MediaStream(s)
 ├─ AudioContext.createMediaStreamSource → optional ChannelMerger (mixed 模式)
 ├─ ScriptProcessorNode (4096 samples)
 │   ├─ onaudioprocess: 取 PCM Float32 →
 │   │  ├─ 推入 pcmChunksRef buffer（供切句后 ingest 用）
 │   │  └─ resample 到 16kHz int16 → base64 → ASR WS append
 │   └─ 连接到 audioCtx.destination (浏览器音频图保活)
 │
 ├─ WebSocket ws://localhost:4928/  (ASR Proxy)
 │   ├─ session.update {turn_detection: server_vad, silence_duration_ms 400}
 │   └─ input_audio_buffer.append {audio: base64 PCM}
 │
 ↓
ASR Proxy (4928) — wss://dashscope.aliyuncs.com/api-ws/v1/realtime
 ↓ DashScope Qwen3-ASR-Flash-Realtime
   ├─ conversation.item.input_audio_transcription.text  (实时片段)
   ├─ conversation.item.input_audio_transcription.completed  (句尾 400ms 静音后)
   └─ input_audio_buffer.speech_started  (segStart anchor)
 ↓
浏览器 ws.onmessage:
   ├─ .text → writeLive(text) 更新「讲话中」气泡
   ├─ .completed → flushSegment(text, segStart, segEnd)
   │    └─ POST /api/utterances/ingest?meetingId=...&text=...
   │       (body: 该 segment 的 WAV bytes)
   └─ .speech_started → 设 segStartMs
```

## 二、三模式音源采集

代码：`web/src/app/page.tsx` `startRecording`

| 模式 | 实现 | 备注 |
|------|------|------|
| 麦克风 | `getUserMedia({audio:{deviceId:{exact:micDeviceId}}})` | enumerateDevices 让用户选具体麦 |
| 系统音频 | `getDisplayMedia({video:true, audio:true})` → 立即 stop video tracks | 需要用户在浏览器弹窗勾「分享标签页音频」 |
| 混合 | mic + display 两路 MediaStream → `createMediaStreamDestination` 合一路 | 单路 PCM 包含双源 |

最后一律用 `AudioContext.createMediaStreamSource(captureStream)` + `ScriptProcessor(4096,1,1)` 接力。

`localStorage` 记 `vp:audioMode` 和 `vp:micDeviceId`，下次进来一键直录就是上次配置。

## 三、PCM 缓存与切句

`pcmChunksRef.current: Float32Array[]` 持续 push 每个 `onaudioprocess` 的 channel 0 copy。

`segStartChunkRef` 记 segment 起点（chunk 数组的 index）。每次 ASR `.completed` 触发：
1. `slice = pcmChunksRef.slice(segStartChunkRef, end)`
2. `concatChunks(slice)` → 一段连续 Float32
3. `resampleToInt16(...)` → 16k Hz int16
4. `encodeWav(...)` → 完整 WAV 文件
5. POST `/api/utterances/ingest`，body 是 WAV bytes

`segStartChunkRef = end` 推进起点。

## 四、ingest 处理

代码：`web/src/app/api/utterances/ingest/route.ts`

1. `audioQualityGate(wav)` → 不过 return `{skipped:true,reason}` 不入库
2. `embedAudio(wav)` POST 声纹服务 4929 → 192d Float32
3. `matchAndAssign(emb, autoMode)` → MatchResult (speakerId / confidence / needsReview / outlierZ ...)
4. INSERT utterances (含 raw_embedding BLOB)
5. `recomputeCentroid(speakerId)` 加权重算
6. `emitUtterance(meetingId, ...)` → SSE 推送到详情页订阅者

## 五、停止录音

`stopRecording`：
- ScriptProcessor disconnect, AudioContext close
- 所有 MediaStream tracks stop()
- WS close（asr-proxy 检测 client closed → 关闭 upstream）
- PATCH `/api/meetings/[id]` `{end:true}` → meetings.ended_at 写时间戳

## 六、关键决策

- **server_vad 而非客户端 VAD**：DashScope 自带 server_vad，切句边界天然对齐 ASR 文本。客户端不需要再跑 Silero VAD。
- **ScriptProcessorNode deprecated 但保留**：AudioWorklet 是后续优化项，不影响功能。浏览器 console 会有 warning。
- **PCM 双消费**：同一份 PCM 既走 WS 给 ASR，又留 buffer 给 ingest 切 WAV。不重复采集。

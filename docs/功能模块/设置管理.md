# 设置管理

## 一、按功能配置（R11 重构）

设计原则：**按功能切分**（ASR / Agent / Voiceprint / Embedding），不是按中转站切分（这样换中转不影响其他功能）。

UI 在 `/settings`，四块独立 section：

| 块 | 字段 | 测试端点 |
|---|---|---|
| 🎤 语音识别 (ASR) | API Key + WS URL | POST /api/asr/ping |
| 🤖 AI 问答 (Agent) | API Key + Provider (PROVIDERS preset) + 自定义 URL + 模型 + System Prompt | POST /api/agent/ping |
| 👤 声纹服务 (Voiceprint) | URL | GET /api/voiceprint-health |
| ✨ Embedding（预留） | API Key + Provider + 自定义 URL + 模型 | POST /api/embedding/ping |

每块独立保存按钮 + 独立测试按钮，互不干扰。

## 二、PROVIDERS 预设（R12 重排）

代码：`web/src/app/settings/page.tsx`

```ts
const PROVIDERS = [
  { label: "llmmelon (推荐)", baseUrl: "https://llmmelon.cloud/v1" },     // 默认
  { label: "云雾中转 (yunwu.ai)", baseUrl: "https://api.yunwu.ai" },
  { label: "Anthropic 官方", baseUrl: "https://api.anthropic.com" },
  { label: "自定义", baseUrl: "" },                                       // 用户填任意 URL
];
```

URL 比较前做 `stripV1` normalize（`u.replace(/\/v1\/?$/, "")`），避免相同 URL 不同后缀被识别成两种 provider。

## 三、DB Schema

代码：`web/src/lib/db.ts`

```sql
CREATE TABLE settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

实际 key 命名约定（functional prefix）：
- `asr_api_key`, `asr_ws_url`
- `agent_api_key`, `agent_base_url`, `agent_model`, `agent_system_prompt`
- `voiceprint_url`
- `embedding_api_key`, `embedding_base_url`, `embedding_model`

旧 key 保留作 fallback（R10 之前用过）：
- `anthropic_api_key` / `anthropic_base_url` / `anthropic_model`
- `dashscope_api_key`

## 四、R12 一次性迁移

代码：`web/src/lib/db.ts` `initDb()` 末尾

启动时检查 `agent_base_url`：
- 没值 / 是 `yunwu.ai` / 是 `yunwu.ai/v1` → 写 `https://llmmelon.cloud/v1`
- 同时 `agent_model` 为空或是旧 sonnet-4-5 → 写 `claude-haiku-4-5-20251001`
- env 有 `LLMMELON_API_KEY` 且 DB 无 agent_api_key → 写入

用户改过自定义值的不动。

## 五、Settings API

代码：`web/src/app/api/settings/route.ts`

| 方法 | 行为 |
|------|------|
| GET | 全部 settings，**API key 字段做脱敏**（首 4 字符 + `••••` + 后 4 字符） |
| PATCH | body 任意 key→value 字典，逐条 `INSERT OR REPLACE` |

**安全**：GET 不返回明文 key，避免浏览器 JS 读取。

## 六、UI API key 不回填明文

代码：`web/src/app/settings/page.tsx`

- 加载 settings 时，发现已存 key 只 setKeySaved(true)，**不把脱敏值填回 input**
- input placeholder 显示「留空保持不变」
- 显示绿色「已配置」标记
- 用户主动输入新值才覆盖（apiKeyChanged 守卫）

## 七、四个 ping 端点

代码各自见：

| 端点 | 实现要点 |
|------|---------|
| POST /api/asr/ping | WebSocket 握手到 asr_ws_url，测延迟 ms |
| POST /api/agent/ping | new Anthropic({apiKey, baseURL}).messages.create("reply OK") |
| GET /api/voiceprint-health | fetch voiceprint_url + /health |
| POST /api/embedding/ping | fetch <embedding_base_url>/embeddings 用最小 input，返回维度 |

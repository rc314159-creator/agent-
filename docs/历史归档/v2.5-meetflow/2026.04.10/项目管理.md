# 项目管理功能

## 需求

MeetFlow 需要支持多项目管理，每次会议对应一个独立项目，数据（画布、转录、AI 对话）完全隔离，刷新后仍可恢复。

## 方案

采用 JSON 文件持久化（无数据库依赖），Next.js API Routes 提供 CRUD，前端通过 Context 全局管理状态。

## 实现内容

### 数据存储

路径：`web/data/projects/<uuid>/`（运行时生成，已加入 `.gitignore`）

每个项目包含：`meta.json`、`outline.html`、`mindmap.json`、`whiteboard.json`、`templates.json`、`transcripts.json`、`chat.json`

全局索引：`web/data/projects/index.json`

### API Routes

| 路由 | 方法 | 说明 |
|------|------|------|
| `/api/projects` | GET | 返回项目列表（读 index.json） |
| `/api/projects` | POST | 创建项目，生成 UUID，初始化所有数据文件 |
| `/api/projects/[id]` | GET | 加载完整项目数据（7 个字段并发读取） |
| `/api/projects/[id]` | PUT | 部分更新（支持任意字段组合），自动更新 updatedAt |
| `/api/projects/[id]` | DELETE | 删除项目目录 + 从索引移除 |

### 前端

- `web/src/hooks/useProject.ts`：`ProjectProvider` Context + `useProject()` hook
  - 应用挂载时自动加载项目列表
  - `saveField(field, data)`：500ms 防抖自动保存
- `web/src/components/layout/ProjectPanel.tsx`：左侧项目列表面板
  - 创建/切换/删除项目
  - 可折叠为 40px 窄条
- `web/src/app/page.tsx`：集成项目管理
  - 无项目时显示欢迎页 + 创建按钮
  - 有项目时渲染完整编辑器布局
